# Keyword-game
Key Word Game — это интерактивная игра на логику и скорость мышления, в которой игроку необходимо угадывать или находить ключевые слова на основе заданных условий. Проект фокусируется на чистой логике, масштабируемой структуре и возможностях дальнейшего расширения (уровни, таймеры, статистика).
