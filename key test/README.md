Полное описание проекта

Key Word Game — это игровое приложение, разработанное с целью тренировки внимания, словарного запаса и реакции пользователя. Игроку предлагается набор условий или подсказок, на основе которых необходимо определить корректное ключевое слово за ограниченное время или количество попыток.

Проект создавался с акцентом на:

чистую архитектуру,

читаемый и расширяемый код,

возможность лёгкой интеграции новых игровых режимов.

🧠 Основная идея

Пользователь получает:

набор подсказок / условий

ограничение по времени или попыткам

Цель — правильно определить ключевое слово, используя логику, ассоциации и внимание к деталям.

🚀 Функциональность

Генерация ключевых слов

Проверка пользовательского ввода

Подсчёт попыток / очков

Обработка ошибок и некорректного ввода

Масштабируемая логика игры

Возможность добавления уровней сложности

🏗 Архитектура проекта

Проект построен с разделением логики:

Game Logic — правила игры, проверки, состояния

Input Handling — обработка пользовательского ввода

Validation Layer — проверка корректности данных

Game State — текущий прогресс, очки, попытки

Такой подход позволяет:

легко тестировать игру

добавлять новые режимы

переиспользовать логику
